# Гант

Универсальная десктоп-программа «Диаграмма Ганта» для управления проектами. Открывает Excel-отчёт 1С, любую таблицу (Excel, CSV, вставку из буфера), MS Project XML и файл обмена `gantt-exchange` (JSON), работает с сервером по открытому HTTP-контракту. Показывает проекты и задания на шкале времени, позволяет править сроки, статусы и цвета, сохраняет в любой из этих форматов, а также в PDF и PNG.

Версия 1.0. Подготовил Averno. **Руководство пользователя** — [docs/guide.md](docs/guide.md), оно же в программе («Справка → Руководство пользователя», Ctrl+F1, можно сохранить в PDF). Что нового — [docs/changes.md](docs/changes.md).

## Установка и обновление

- **`dist\GanttSetup-1.0.0.exe`** — установщик: двойной щелчок, «Установить». Ставится для одного пользователя, без прав администратора, в `%LOCALAPPDATA%\Programs\Гант`; ярлыки на рабочем столе и в «Пуске»; удаление — «Параметры → Приложения».
- **Обновление программы:** содержимое `dist\update` (`latest.json` + установщик) положите в общую папку или на сайт — это источник обновлений. Установщик, запущенный из этой папки, запомнит её сам; иначе источник указывается в «Настройки → Обновление программы». Программа проверяет его при запуске и обновляется сама («Справка → Проверить обновления», «Обновить из файла…»).
- **Обновления с GitHub:** источник `github:владелец/репозиторий` (открытый репозиторий). Выложить версию: `set GITHUB_TOKEN=…` и `.venv\Scripts\python tools\publish_github.py владелец/репозиторий` (или `--prepare` и загрузить файлы на сайте). Источник по умолчанию — выпуски этого репозитория (`UPDATE_SOURCE` в `gantt\__init__.py`).
- Для администратора: `GanttSetup-1.0.0.exe --install --silent [--dir ПАПКА] [--no-desktop] [--update-source ПАПКА]`, `Gantt.exe --update` (обновить без окон), `Gantt.exe --uninstall --silent`. Подробнее — раздел «Для администратора» в руководстве.

## Как запустить

- **`dist\Gantt.exe`** — один файл, Python не нужен, можно запускать и без установки. Файл можно перетащить на .exe или передать в командной строке: `Gantt.exe "путь\к\отчёту.xlsx"`.
- **Двойной щелчок по `run.bat`** — запуск из исходников. При первом запуске он сам создаст окружение и поставит зависимости (нужен Python 3.11+), дальше открывается сразу.
- Файл можно передать сразу: перетащить его на `run.bat` или запустить `run.bat "путь\к\отчёту.xlsx"`.
- Для разработки: `.venv\Scripts\python -m gantt [путь]`, тесты — `.venv\Scripts\python -m pytest`, тестовый сервер отдельно — `.venv\Scripts\python -m gantt.mock_server`.
- Собрать: `.venv\Scripts\python -m pip install -r requirements-dev.txt`, затем `.venv\Scripts\python tools\build_exe.py` → `dist\Gantt.exe`, `dist\GanttSetup-<версия>.exe`, `dist\update\`.
- Новая версия: номер — в `gantt\__init__.py`, что нового — раздел в `docs\changes.md`, затем сборка.
- Демо-данные (`examples/`) полностью выдуманы и пересоздаются `tools\make_demo.py`; иконка — `tools\make_icon.py`; картинки руководства — `tools\make_guide_images.py`.

## Что умеет

**Открыть** (меню «Файл», перетаскивание в окно, командная строка):
- отчёт 1С ProjectsToGanttExport — сразу, встроенным шаблоном;
- любую другую таблицу Excel/CSV — мастером: какая колонка что значит, как устроена вложенность, что значат статусы; сопоставление запоминается шаблоном, дальше такие таблицы открываются сразу;
- таблицу из буфера обмена — Ctrl+Shift+V (скопируйте строки вместе с заголовками);
- MS Project XML, файл обмена `.json`, а также пакет правок (`changes`), ответ источника (`results`) и изменения источника (`incremental`).

**Смотреть:** раздел → проект → задания со сворачиванием «+/−»; масштаб от дня до года с плавным переходом; зажатое колесо мыши тянет диаграмму в любую сторону; режим картошки для слабых ПК; поиск, фильтры и сохранённые наборы фильтров; режимы «Все / Мои»; 8 тем; пастельные цвета проектов, названные словами.

**Править:** план, факт, статус, цвет проекта — двойной щелчок, F2, правая кнопка или перетаскивание полосы. Отмена — Ctrl+Z. Правки хранятся на этом ПК, переживают перезапуск и новые выгрузки отчёта; расхождения с источником показываются на выбор.

**Сохранить как…** — формат выбирается в окне, для каждого сказано, что в нём не сохранится: файл обмена (без потерь), Excel «Гант-таблица» (с листом «Диаграмма»), CSV, MS Project XML, PDF (A4/A3, по листам), PNG. Всё сохранённое открывается обратно. Отдельно: «Лист изменений» (Excel или PDF) и «Выгрузить правки файлом обмена».

**Сервер:** «Сервер → Подключение к серверу» — адрес, логин (пароль хранится в Windows), «Проверить соединение». Данные обновляются сами (только изменения), правки уходят в источник только после «Подтвердить», без связи — работа на последней копии с повтором.

### Что попробовать

1. «Посмотреть на демо-данных» → поправьте срок перетаскиванием полосы → «Изменения» справа вверху.
2. «Сохранить как…» → PDF → откройте файл.
3. Скопируйте в Excel несколько строк с заголовками → в программе Ctrl+Shift+V → мастер.
4. «Подключиться к серверу…» → «Запустить тестовый сервер на этом ПК» → «Подключиться». Поправьте срок → «Сервер → Отправить правки…» → «Подтвердить». Раз в минуту тестовый сервер сам что-нибудь меняет — изменения приходят без перезагрузки.

Где лежат данные программы: `%LOCALAPPDATA%\Гант` — правки (`data.sqlite`), настройки (`settings.ini`), шаблоны таблиц (`templates.json`), подключения без паролей (`connections.json`), копии данных с сервера (`cache\`), данные тестового сервера (`test-server.json`). Пароли — только в диспетчере учётных данных Windows.
