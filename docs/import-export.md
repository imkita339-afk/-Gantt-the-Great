# Источники данных и форматы файлов

Программа универсальная: её ядро знает только [файл обмена](format.md). Каждый внешний формат — отдельный **адаптер**, который переводит данные в файл обмена и обратно. Новый формат добавляется новым адаптером, ядро и интерфейс не меняются.

## Что можно открыть и сохранить

| Формат | Открыть | Сохранить | Что теряется при сохранении | Этап |
|---|---|---|---|---|
| Файл обмена `.json` | ✅ | ✅ | ничего | 1 |
| Excel `.xlsx` | ✅ шаблон или мастер | ✅ | версии, `editable`, очередь правок | 1 / 2 |
| CSV `.csv` | ✅ мастер | ✅ | то же и цвета справочников | 1 / 2 |
| Таблица из буфера обмена | ✅ мастер | — | — | 1 |
| MS Project XML `.xml` | ✅ | ✅ | смысл статусов (уходит в текстовое поле), цвета, шкалы | 3 |
| PDF, PNG | — | ✅ | это картинка, данные из неё не читаются | 3 |
| Сервер по [HTTP-контракту](api.md) | ✅ | ✅ правки после «Подтвердить» | — | 3 |

- **Открыть** — меню «Файл → Открыть…», перетаскивание в окно, командная строка `Gantt.exe путь`.
- **Сохранить** — «Файл → Сохранить как…»: пользователь сам выбирает тип файла в списке. Если формат что-то теряет, программа заранее показывает, что именно.

Всё, что программа сохранила в Excel, CSV или MS Project, она же открывает обратно без мастера.

## Таблицы: Excel, CSV, буфер обмена

### Встроенные шаблоны

Программа сама узнаёт знакомые таблицы по заголовкам колонок:

- **Отчёт 1С ProjectsToGanttExport.** Иерархия — группировка строк Excel: раздел → проект → строки заданий. Колонки ищутся по заголовкам («Проект», «Дата начала план», «Дата окончания план», «Дата начала», «Дата окончания», «Задание», «Текущий исполнитель», «Дата», «Крайняя дата выполнения», «Дата выполнения»); недостающие — не ошибка. «Задание» вида «Вид № Номер от дд.мм.гг (Тема)» разбирается на вид, номер и тему; ключ задания — номер. Статус, если его нет в отчёте, вычисляется по датам (правила — в CLAUDE.md).
- **Гант-таблица** — то, что сохраняет сама программа (см. ниже).

### Мастер сопоставления колонок

Для любой другой таблицы. Слева — предпросмотр первых строк, справа — настройки:

1. **Лист и строка заголовков** — определяются сами, можно поправить.
2. **Колонки → поля:** название, номер, исполнители, инициатор, план/факт начала и окончания, процент, статус, приоритет, срочность, влияние, категория. Остальные колонки можно взять как пользовательские поля или пропустить. Программа угадывает по заголовкам («Наименование», «Тема», «Name»…).
3. **Иерархия** — одно из:
   - группировка строк Excel (как в отчёте 1С);
   - колонка «Уровень»;
   - нумерация «1 / 1.2 / 1.2.3»;
   - колонка «Родитель»;
   - отступ текста;
   - плоский список.

   Названия уровней задаются здесь же.
4. **Статус** — одно из:
   - по значениям колонки: каждому встреченному значению ставится смысл (выполнено, в работе…); символы ✔ ▶ ⚠ и слова «выполн», «заверш», «просроч» распознаются сами;
   - по датам — те же правила, что для отчёта 1С (см. [CLAUDE.md](../CLAUDE.md)).
5. **Ключ строки** — колонка с номером или кодом, если есть. Если нет — путь по названиям (раздел / проект / задача). Тогда переименование строки в Excel выглядит как «удалили и добавили» — это ограничение источника, программа предупреждает о нём.

Сопоставление сохраняется как **шаблон**. Следующая таблица с теми же заголовками откроется сразу, без мастера.

### Разбор значений

- **Даты:**
  - ячейки-даты Excel;
  - текст `дд.мм.гггг`, `дд.мм.гг`, `ГГГГ-ММ-ДД`, с временем и без;
  - `—`, `-` и пустая ячейка — нет даты.

  Порядок день/месяц настраивается для таблиц из англоязычных систем.
- **Процент:** «60%», «60», «0,6», «▶ 60% (3/5)».
- **Люди:** через запятую, точку с запятой или с новой строки. Полное ФИО показывается как «Фамилия И.О.».
- **CSV:** разделитель (`;` `,` табуляция) и кодировка (UTF-8, Windows-1251) определяются сами.

### Повторная загрузка

Тот же файл или та же выгрузка → те же ключи → те же узлы. Правки из очереди сохраняются и сверяются с новыми значениями, расхождения показываются как конфликты.

Если включено слежение за файлом, программа сама перечитывает таблицу при изменении. Так удобно работать с отчётом, который 1С регулярно сохраняет в одну и ту же папку.

## Сохранение в форматы

- **Файл обмена** — всё без потерь: данные, справочники, версии, очередь правок (`kind: full` с `changes`). Формат по умолчанию для «Сохранить».
- **Excel — «Гант-таблица»:**
  - лист «Данные»: строки с группировкой по уровням и отступами, колонки как в программе (видимые и в том же порядке), служебные колонки «ID» и «Родитель» справа;
  - лист «Справочники»: статусы с цветами, шкалы, люди — чтобы файл открывался обратно без потерь данных;
  - по желанию лист «Диаграмма»: понедельная шкала с цветными ячейками, как в привычном Excel-Ганте, — для печати и руководителя.
- **CSV** — одна таблица как лист «Данные». Кодировка UTF-8 с BOM и разделитель `;`, чтобы русский Excel открыл файл двойным щелчком.
- **MS Project XML** — формат, который понимают MS Project, ProjectLibre, GanttProject:
  - уровни → структура задач;
  - план → «Начало/Окончание», факт → «Фактическое начало/окончание»;
  - процент, вехи, зависимости;
  - исполнители → ресурсы и назначения;
  - статус, срочность, влияние, пользовательские поля → настраиваемые поля.
- **PDF / PNG** — картинка диаграммы той же отрисовкой, что на экране, на светлом фоне:
  - строки — «как на экране» (фильтры, раскрытие) или «всё раскрыто, без фильтров»;
  - период — весь период строк или только видимый участок шкалы;
  - PDF — A4 или A3, альбомный: весь период по ширине листа, строки переносятся на следующие листы, на каждом — заголовок, дата и «лист N из M».

Excel, CSV и MS Project получают видимые значения (правки уже внутри), а сохранённая таблица при открытии — **свой набор данных**: её правки не смешиваются с правками исходного отчёта.

## Лист изменений

Пока нет связи с 1С, правки нельзя записать туда автоматически. «Файл → Лист изменений…» сохраняет очередь для ручного внесения или для администратора 1С. Колонки: раздел / проект, что, №, поле, было (в источнике), стало; в шапке — кто и когда сформировал. Формат — Excel или PDF (с местом для подписи), по выбору.

Для другой программы или источника — «Файл → Выгрузить правки файлом обмена…» (документ `changes`, без цветов).

## Как устроен адаптер

```python
class FormatAdapter(Protocol):
    id: str                      # "xlsx-table", "msproject-xml"…
    title: str                   # «Excel», «MS Project XML» — для списка типов файлов
    extensions: tuple[str, ...]  # (".xlsx",)
    can_read: bool
    can_write: bool

    def sniff(self, path) -> float: ...                        # насколько файл похож на «свой», 0…1
    def read(self, path, options) -> ReadResult: ...            # документ + предупреждения
    def write(self, document, path, options) -> WriteResult: ... # + список того, что потеряно
```

Адаптеры регистрируются в одном списке. Меню «Открыть», «Сохранить как», командная строка и перетаскивание берут форматы оттуда.
