# Открытые вопросы и риски

## Вопросы

Ни один вопрос не блокирует Этап 1. Без ответа действует предложенное решение.

| # | Вопрос | Предлагаю, пока нет ответа |

| 1 | Можно ли добавить в отчёт ProjectsToGanttExport поля «Статус» и «Процент» через его настройки? | Тогда программа возьмёт настоящие значения; пока — вычисляет по датам. |
| 2 | Что за параметр в строке «Параметры» шапки отчёта? | Не используем. |

| 4 | Показывать ли пустые проекты (без заданий и дат)? | Показывать без полосы; фильтр «Скрыть пустые». |
| 5 | Полные шкалы приоритета, срочности и влияния в 1С — сколько значений? | В примерах по 4: «Очень низкий» … «Высокий». |
| 6 | Нужна ли «Открыть в источнике»? В Excel-отчёте ссылок нет. | Формат поддерживает `url`, пункт меню появляется, только если ссылка есть. |

| 10 | С сервером (Этап 3): отправлять ли подтверждённые, но не отправленные правки при восстановлении связи? ТЗ запрещает отправку без «Подтвердить». | Нет: после восстановления связи — снова «Подтвердить». |

## Риски

| Риск | Что делаем |
|---|---|
| **Репозиторий публичный**, а в ТЗ и документах есть названия проектов и конфигурации | Реальные данные — только в `local/`. Push — после смены видимости на приватную. |
| **Запись в 1С недоступна** без человека с доступом к конфигуратору | Контракт [api.md](api.md) готов для него; до тех пор — лист изменений. |
| **Ключ проекта в Excel — название.** Переименование в 1С даст «новый» проект, правки к старому станут конфликтом «узел удалён». | Предупреждать в отчёте об открытии; если в отчёт добавить код проекта — ключом станет он. |
| **Один .exe медленно стартует** (распаковка) и может смущать антивирус | Пробная сборка на Этапе 1, решение по замеру. |
| **Сетевые папки:** уведомления об изменении файла ненадёжны, файл может читаться недописанным | Запасной опрос, пауза, повторы. |
| **Синхронность дерева и шкалы** при анимированном раскрытии | Общая раскладка строк, делаем первой на Этапе 1. |
| **Отчёт 1С меняет набор колонок** между версиями | Поиск колонок по заголовкам, недостающие — пустые. |
